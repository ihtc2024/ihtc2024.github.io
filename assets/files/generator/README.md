# IHTC-2024 Instance Generator

## Requirements

- Python ≥ 3.2  
- Required libraries: `json`, `statistics`, `numpy`, `copy`, `math`, `argparse`, `os`  
  (all part of the Python standard library except `numpy`)

---

## Usage

Run the generator with:

```bash
python generate.py [arguments]
```

If no arguments are specified, a mix of random and fixed values are used and the generated instance is printed to `stdout`.

---

## Arguments

- `--output, -o` : Output file (JSON format). Prints to `stdout` if omitted.  
- `--weeks, -w` : Scheduling horizon (in weeks). Default: randomly selected between 2 and 4. Any positive integer is allowed.  
- `--patients, -p` : Number of patients.  
- `--patients_density, -pd` : Daily mean number of patient admissions.  
- `--mandatory_ratio, -m` : Expected ratio of mandatory patients over total patients.  
- `--surgeons, -s` : Number of surgeons.  
- `--operating_theaters, -t` : Number of operating theaters.  
- `--rooms, -r` : Number of rooms.  
- `--skills, -k` : Number of skills (integer between 2 and 5).  
- `--age_groups, -a` : Number of age groups (integer between 2 and 5).  
- `--overwrite, -ow` : Overwrite the output file if it already exists.

---

## Instance Generation

Official IHTC-2024 competition instances were generated by ranging the following parameters within the specified ranges:

- patient density  
- mandatory patient ratio  

All remaining parameters were sampled randomly.

---

## Disclaimer

The generator is designed to reduce the likelihood of producing infeasible instances; however, **feasibility is not guaranteed**.
